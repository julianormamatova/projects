Аннотация

Инструкция описывает безопасную установку и настройку веб-сервера nginx и запуска на нем веб-страницы с помощью менеджера пакетов Homebrew на системе macOS 13.3 (Ventura) для локального тестирования. Инструкция предназначена для начинающих пользователей, которые изучают веб-технологии и хотят ознакомиться с nginx.

nginx (engine x) — высокопроизводительный веб-сервер с открытым исходным кодом, который часто используется для обслуживания статических веб-страниц.

Ограничение ответственности (Disclaimer)
  • Перед внесением изменений в конфигурацию сервера обязательно создайте резервную копию конфигурационного файла.
  • Не используйте эту конфигурацию в production‑среде без консультации с системным администратором.
  • Изменение системных настроек и работа с правами sudo несёт риски: при ошибках можно нарушить работу сервисов или потерять доступ к файлам.

Предварительные требования

  • Установленный Homebrew. Если его нет — см. раздел 1.
  • Базовое знание интерфейса командной строки (Terminal).
  • Доступ администратора (права sudo) на компьютере.
  • Текстовый редактор (рекомендуется VS Code, TextEdit или любой другой).

Перед началом работы рекомендуется ознакомиться с документацией:

  • nginx:
    • официальная документация
    • руководство для начинающих
  • Homebrew: Homebrew Docs

Системные требования

nginx — легковесный веб-сервер, и его минимальные требования крайне невысоки. Ниже представлен минимальный набор для локальной разработки.

Компонент Требования
macOS10.15 (Catalina) или новее
ПроцессорIntel (x86_64) или Apple Silicon (ARM64)
Homebrew3.0.0 или новее
Свободное место на диске~50 МБ
Оперативная памятьот 512 МБ (для комфортной работы с редактором и браузером — от 2 ГБ)
nginx эффективно работает даже на старых Mac и на виртуальных машинах с 1 ядром.

Полезные команды

Ниже представлены базовые команды nginx.

Управление сервером

Команда Описание
sudo nginxЗапустить nginx (если не работает через brew services)
sudo nginx -s stopОстановить сервер
sudo nginx -s reloadПерезагрузить конфигурации без остановки сервера
sudo nginx -s reopenПереоткрыть лог-файлов
brew services start nginxЗапустить через Homebrew (фоновый режим)
brew services restart nginxПерезапустить через Homebrew

Проверка конфигурации

Команда Описание
sudo nginx -tПроверить синтаксис конфига (обязательно перед reload!)
sudo nginx -TПроверить синтаксис + вывести весь конфиг в терминал

Логи и отладка

Команда Описание
tail -f /opt/homebrew/var/log/nginx/access.logПросмотреть логи доступа в реальном времени

Работа с файлами

Команда Описание

Эти команды решают повседневные задачи. Для продвинутых сценариев (например, настройка SSL, балансировки нагрузки) см. официальную документацию nginx.

1. Подготовка системы и установка Homebrew

Homebrew — утилита командной строки для установки пакетов и приложений в macOS.

Если Homebrew ещё не установлен:

  1. Откройте Терминал и вставьте команду c официального сайта brew.sh: 
    /bin/bash -c "\$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  2. Введите пароль администратора для подтверждения (ввод пароля не отображается).
Во время установки Homebrew запрашивается пароль администратора (sudo), так как требуются права root для установки в системные директории. Вводите пароль только при уверенности в источнике скрипта.
  1. Нажмите Return и дождитесь завершения установки (может занять несколько минут). Появится строка Installation successful!
  2. Убедитесь в корректности установки через команду проверки версии: 
    brew --version

2. Установка и запуск nginx

Чтобы установить nginx с помощью Homebrew:

  1. Откройте Терминал и введите команду: 
    brew install nginx
  2. Дождитесь завершения. Homebrew автоматически установит все зависимости.
  3. Запустите сервер: 
    brew services start nginx
  4. Проверьте статус (должно быть started): 
    brew services list
  5. Для проверки работоспособности перейдите по адресу в браузере: http://localhost:8080/.
Порт 8080 используется по умолчанию для избежания конфликтов с другими сервисами и чтобы не требовать постоянных прав суперпользователя.

3. Настройка nginx

3.1. Создание рабочей директории

Создайте корневую папку для файлов сайта, например, на рабочем столе:

mkdir -p ~/Desktop/mywebsite

Запомните этот путь — он понадобится для настройки root в конфигурации nginx.

3.2. Поиск конфигурационного файла

Точный путь к конфигурационному файлу можно узнать командой:

brew info nginx

В выводе ищите строку вида: Configuration files are at: /opt/homebrew/etc/nginx.

Обычно файл находится по пути: /opt/homebrew/etc/nginx/nginx.conf.

Путь может отличаться в зависимости от конфигурации Homebrew. Всегда проверяйте его через brew info nginx.

3.3. Создание резервной копии конфигурации

Перед любыми правками обязательно создайте резервную копию:

sudo cp /opt/homebrew/etc/nginx/nginx.conf /opt/homebrew/etc/nginx/nginx.conf.backup

Это позволит быстро восстановить рабочую конфигурацию при ошибках.

3.4. Редактирование конфигурации

Откройте конфигурационный файл в текстовом редакторе (пример для VS Code):

sudo code /opt/homebrew/etc/nginx/nginx.conf
При редактировании конфигураций с sudo будьте внимательны: ошибки могут остановить сервер.

Внутри файла найдите блок server { ... }. В нём нужно изменить два параметра:

  • listen: по умолчанию стоит 8080; если вы хотите оставить этот порт, ничего не меняйте. Если хотите использовать порт 80, измените на listen 80;.
Порт 80 требует прав суперпользователя и может конфликтовать с другими сервисами. Для обучения лучше оставить 8080.
  • root: по умолчанию часто стоит путь к тестовой директории Homebrew. Замените его на вашу рабочую директорию: 
    root /Users/ВАШ_ПОЛЬЗОВАТЕЛЬ/Desktop/mywebsite;
    Где ВАШ_ПОЛЬЗОВАТЕЛЬ — ваше имя пользователя macOS (узнать можно командой whoami).

Пример изменённого блока server (с портом 8080):

server {
    listen 8080;
    server_name localhost;

    root /Users/ВАШ_ПОЛЬЗОВАТЕЛЬ/Desktop/mywebsite;
    index index.html;

    location / {
        try_files $uri $uri/ =404;
    }
}

Сохраните файл и закройте редактор.

3.5. Проверка синтаксиса конфигурации

Перед перезагрузкой обязательно проверьте синтаксис:

sudo nginx -t

Если вывод содержит syntax is ok и test is successful, конфигурация корректна. Если есть ошибки — исправьте их и повторите проверку.

Перезагрузите конфигурацию без остановки сервера:

sudo nginx -s reload

4. Создание HTML-файла

Чтобы nginx отображал страницу, в корневой директории должен быть файл index.html.

  1. Создайте файл: 
    touch ~/Desktop/mywebsite/index.html
  2. Откройте его в редакторе и вставьте базовый HTML‑код: 
    <!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Моя первая веб-страница</title>
</head>
<body>
    <h1>Привет, мир!</h1>
    <p>Это моя первая веб-страница, которую обслуживает nginx!</p>
</body>
</html>
  3. Сохраните файл.
  4. Убедитесь, что файл существует в нужной директории: 
    ls -l ~/Desktop/mywebsite/

5. Просмотр веб-страницы

Откройте браузер и перейдите по адресу:

  • если вы оставили порт 8080: http://localhost:8080/;
  • если вы изменили на порт 80: http://localhost/.

Вы должны увидеть страницу с заголовком Привет, мир!, как на рисунке ниже.

Устранение неполадок (Troubleshooting)

Не запускается nginx

Симптомы:

  • команда brew services start nginx завершается ошибкой;
  • при переходе на http://localhost страница не загружается.

Решение:

  1. Проверить статус nginx: 
    brew services list
  2. Если статус не started, выполнить: 
    brew services restart nginx

Ошибки в конфигурации

Симптомы:

  • после sudo nginx -t появляются сообщения о синтаксических ошибках;
  • nginx перестает отвечать после reload.

Решение:

  1. Проверить синтаксис командой: 
    sudo nginx -t
  2. Если ошибка указывает на строку (например, line 25), открыть конфиг: 
    sudo code /opt/homebrew/etc/nginx/nginx.conf
  3. Убедиться, что все { } и ; на месте.
  4. Проверить корректность пути (например, /Users/username/Desktop/mywebsite).
  5. Восстановить рабочую версию конфига из резервной копии: 
    sudo cp /opt/homebrew/etc/nginx/nginx.conf.backup /opt/homebrew/etc/nginx/nginx.conf

Страница отображается некорректно

Симптомы: в браузере отображаются символы вместо текста.

Решение:

  1. Проверить кодировку HTML-файла:
    • Открыть index.html в VS Code.
    • В правом нижнем углу кликнуть на кодировку (должно быть: UTF-8).
    • Если указана другая, то нажать Save with Encoding → UTF-8.
  2. Проверить наличие мета-тега <meta charset="UTF-8"> в <head>.
