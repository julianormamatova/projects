# Docker: Установка и локальный запуск веб-страницы на macOS

Инструкция описывает установку и базовую настройку **Docker** на **macOS**, а также создание Docker-файла для сборки контейнера с простой веб-страницей и запуск этого контейнера для локального тестирования в браузере. Инструкция предназначена для начинающих пользователей, которые изучают веб-технологии и хотят ознакомиться с **Docker**.

> [!IMPORTANT]
> **Ограничение ответственности (Disclaimer)**
> - Перед внесением изменений в конфигурацию сервера **обязательно создайте резервную копию** конфигурационного файла.
> - Не используйте эту конфигурацию в production‑среде без консультации с системным администратором.
> - Изменение системных настроек и работа с правами `sudo` несёт риски: при ошибках можно нарушить работу сервисов или потерять доступ к файлам.
