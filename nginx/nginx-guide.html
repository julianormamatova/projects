Аннотация

Инструкция описывает безопасную установку и настройку веб-сервера nginx и запуска на нем веб-страницы с помощью менеджера пакетов Homebrew на системе macOS 13.3 (Ventura) для локального тестирования. Инструкция предназначена для начинающих пользователей, которые изучают веб-технологии и хотят ознакомиться с nginx.

nginx (engine x) — высокопроизводительный веб-сервер с открытым исходным кодом, который часто используется для обслуживания статических веб-страниц.

Ограничение ответственности (Disclaimer)
  • Перед внесением изменений в конфигурацию сервера обязательно создайте резервную копию конфигурационного файла.
  • Не используйте эту конфигурацию в production‑среде без консультации с системным администратором.
  • Изменение системных настроек и работа с правами sudo несёт риски: при ошибках можно нарушить работу сервисов или потерять доступ к файлам.

Предварительные требования

  • Установленный Homebrew. Если его нет — см. раздел 1.
  • Базовое знание интерфейса командной строки (Terminal).
  • Доступ администратора (права sudo) на компьютере.
  • Текстовый редактор (рекомендуется VS Code, TextEdit или любой другой).

Перед началом работы рекомендуется ознакомиться с документацией:

  • nginx:
    • официальная документация
    • руководство для начинающих
  • Homebrew: Homebrew Docs

Системные требования

nginx — легковесный веб-сервер, и его минимальные требования крайне невысоки. Ниже представлен минимальный набор для локальной разработки.

Компонент Требования
macOS10.15 (Catalina) или новее
ПроцессорIntel (x86_64) или Apple Silicon (ARM64)
Homebrew3.0.0 или новее
Свободное место на диске~50 МБ
Оперативная памятьот 512 МБ (для комфортной работы с редактором и браузером — от 2 ГБ)
nginx эффективно работает даже на старых Mac и на виртуальных машинах с 1 ядром.

Полезные команды

Ниже представлены базовые команды nginx.

Управление сервером

Команда Описание
sudo nginxЗапустить nginx (если не работает через brew services)
sudo nginx -s stopОстановить сервер
sudo nginx -s reloadПерезагрузить конфигурации без остановки сервера
sudo nginx -s reopenПереоткрыть лог-файлов
brew services start nginxЗапустить через Homebrew (фоновый режим)
brew services restart nginxПерезапустить через Homebrew

Проверка конфигурации

Команда Описание
sudo nginx -tПроверить синтаксис конфига (обязательно перед reload!)
sudo nginx -TПроверить синтаксис + вывести весь конфиг в терминал

Логи и отладка

Команда Описание
tail -f /opt/homebrew/var/log/nginx/access.logПросмотреть логи доступа в реальном времени
tail -f /opt/homebrew/var/log/nginx/error.logПросмотреть ошибки в реальном времени
sudo lsof -i :80Проверить, какой процесс использует порт 80

Работа с файлами

Команда Описание
sudo code /opt/homebrew/etc/nginx/nginx.confОткрыть конфиг в VS Code
sudo cp nginx.conf nginx.conf.backupСоздать резервную копию конфига
sudo diff nginx.conf nginx.conf.backupСравнить текущий конфиг с резервной копией
Эти команды решают повседневные задачи. Для продвинутых сценариев (например, настройка SSL, балансировки нагрузки) см. официальную документацию nginx.

1. Подготовка системы и установка Homebrew

Homebrew — утилита командной строки для установки пакетов и приложений в macOS.

Если Homebrew ещё не установлен:

  1. Откройте Терминал и вставьте команду c официального сайта brew.sh: 
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  2. Введите пароль администратора для подтверждения (ввод пароля не отображается).
Во время установки Homebrew запрашивается пароль администратора (sudo), так как требуются права root для установки в системные директории. Вводите пароль только при уверенности в источнике скрипта.
  1. Нажмите Return и дождитесь завершения установки (может занять несколько минут). Появится строка Installation successful!
  2. Убедитесь в корректности установки через команду проверки версии: 
    brew --version

2. Установка и запуск nginx

Чтобы установить nginx с помощью Homebrew:

  1. Откройте Терминал и введите команду: 
    brew install nginx
  2. Дождитесь завершения. Homebrew автоматически установит все зависимости.
  3. Запустите сервер: 
    brew services start nginx
  4. Проверьте статус (должно быть started): 
    brew services list
  5. Для проверки работоспособности перейдите по адресу в браузере: http://localhost:8080/.
